# Sulphur Mountain Eco-Village Interactive Map - Complete Development Specification

## PROJECT OVERVIEW
Build an interactive 2D map interface for the Sulphur Mountain Eco-Village (11962 Sulphur Mountain Road, Upper Ojai, CA) that serves as an immersive investor presentation and project visualization tool. The map will feature clickable project zones, detailed information cards, 3D visual elements, and smooth navigation controls.

## BRAND IDENTITY & STYLING
**Base the design on existing website:** https://sulphurmountainroad.vercel.app
- Clean, modern interface with earth-tone color palette
- Professional presentation suitable for investors
- Integration with existing "digital twin" and eco-village narrative
- Responsive design for desktop and mobile viewing

## TECHNICAL REQUIREMENTS

### Core Technology Stack
- **Mapping Library:** Leaflet.js or Mapbox GL JS for interactive map functionality
- **Framework:** React.js with modern hooks for state management
- **Styling:** Tailwind CSS for rapid development and consistency
- **3D Elements:** CSS 3D transforms and/or Three.js for simple 3D overlays
- **Image Management:** Custom tile server setup for aerial imagery integration
- **Data Structure:** JSON-based project database for easy content management

### Map Foundation
- Convert provided aerial imagery (10-acre property with red boundary lines) into interactive map tiles
- Implement smooth zoom levels (3-5 levels recommended)
- Pan and zoom controls with momentum scrolling
- Property boundary overlay matching the red lines from aerial photo
- Coordinate system mapped to real-world GPS coordinates if available
